# لاوین — فرانت‌اند فروشگاه (HTML / CSS / JS خالص)

```
index.html  shop.html  product.html  cart.html  checkout.html   ← صفحات سایت
assets/
  css/style.css          ← استایل سایت
  js/app.js              ← منطق مشترک سایت (سبد، علاقه‌مندی، جستجو، صفحات)
  js/data.js             ← محصولات، دسته‌ها، بنرها، نظرات (پیش‌فرض)
  js/theme.js            ← اعمال تم فعال (رنگ و فونت)
  img/products/          ← عکس محصولات (مسیر را در فیلد images از data.js بنویسید)
  img/demo/              ← عکس‌های نمونه
admin/
  index.html             ← پنل مدیریت
  assets/admin.css  admin.js
```

## اجرا
فایل‌ها را با یک وب‌سرور محلی باز کنید (نه مستقیم با دوبار کلیک)، مثلا `npx serve` یا Live Server در VS Code.
سایت و پنل باید از یک آدرس سرو شوند، چون فعلا داده‌ها در localStorage مرورگر ذخیره می‌شوند.

## ورود به پنل
`/admin/` — نام کاربری `admin`، رمز `lavin1405` (فقط نمایشی؛ در `admin/assets/admin.js` بالای فایل، قبل از انتشار باید با احراز هویت واقعی عوض شود).

## نقاط تنظیم
- شماره کارت و `ONLINE` پرداخت: `assets/js/app.js` (یا از پنل ← تنظیمات)
- تاریخ پایان پیشنهاد ویژه: `OFFER_END` در `assets/js/app.js` (یا از پنل ← محتوای سایت)
- تم، رنگ و فونت: پنل ← تم و ظاهر سایت

## مرحله بعد
اتصال بک‌اند: محصولات، سفارش‌ها، تنظیمات، تم و محتوا از localStorage به API منتقل شوند.
